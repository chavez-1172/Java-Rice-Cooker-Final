Logical Operators (Combining Questions)

Logical operators let you combine conditions to check if one of those or ALL of those are true or false. Logical operators let you chain questions together.


1. AND Operator ( && )

  • Uses two ampersand ( && ) symbols and checks if both values are true. Note that both conditions MUST be true!

  • You will only eat the snack if it is Sweet AND Chocolate. (If it's sweet but vanilla, you walk away!)


    • Sample Code AND ( && ) Operator:

                    public class andOperator{
                    public static void main(String[] args){
                        boolean isSweet = true;
                        boolean isChocolate = false;

                        if (isSweet && isChocolate) {
                            System.out.println("I will eat the snack!");
                        } else {
                            System.out.println("Not what I wanted.");
                        }

         /*We have two boolean variables which are 
        isSweet and isChocolate wherein only the isSweet is true.
        Using the AND && operator which checks if both values are true, which statement do you think 
        will be printed?*/

         /*That's right! The else-condition will be the one executed since one of the variables
        are false. This immediately makes the if-condition false.*/

        OUTPUT: Not what I wanted.
                    }
                }

    2. OR Operator ( || )

  • Uses two vertical pipe ( || ) symbols and checks if atleast ONE of the values are true. Even if one condition is false, and the other is true, it will still be true!

  • The dog will fetch the item if it is a Tennis Ball OR a Stick. (Either one makes the dog happy!)


    • Sample Code OR ( || ) Operator:

                    public class andOperator{
                    public static void main(String[] args){
                        boolean isTennisBall = false;
                        boolean isStick = true;

                        if (isTennisBall || isStick) {
                            System.out.println("Dog fetches the item!");
                        } else {
                            System.out.println("Dog ignores it.");
                        }

         /*We have two boolean variables which are 
        isTennisBall and isStick wherein only the isStick is true.
        Using the OR || operator which checks if atleast ONE of the values are true, 
        which statement do you think will be printed?*/

         /*This time, the if-condition will be the one executed since 
        the whole if-codition returns true because ONE of them is true. 
        Regardless of the one false value, it will still be true.

        This immediately makes the if-condition true.*/

        OUTPUT: Dog fetches the item!
                    }
                }

    3. NOT Operator ( ! )

  • Uses exclamation point ( ! ) symbol and reverses a true to false, or false to true. It is used to invert or reverse a boolean value.

  • !isCatAwake means "The cat is asleep."


    • Sample Code NOT ( ! ) Operator:

                    public class andOperator{
                    public static void main(String[] args){
                        boolean isCatAwake = false;

                if (!isCatAwake) {
                    System.out.println("The cat is asleep.");
                }

         /*We have one boolean variable named
        isCatAwake whose value is true.
        Using the NOT ! operator which reverses the value of a boolean, 
        do you think the statement will still be printed even if the value of isCatAwake is false?*/

         /*That's right! The if condition will be executed since even if the 
        original value of the isCatAwakeis false, it became true once we used the 
        NOT ! operator on the if-condition.*/

        OUTPUT: The cat is asleep.
                    }
                }
