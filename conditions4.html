The Three Types of Conditional Structures

In programming, conditional statements are instructions that tell a program to perform different actions based on whether a specified condition evaluates to true or false.


1. The If Statement

  • The simplest check. Code inside an if block only runs if the condition passes or is equal to true. If it fails, Java ignores the block entirely and keeps moving down.


    • 2. The if-else Statement

  • Gives your program two distinct paths. Path A happens if the condition is true; Path B happens if it's false. If the if or first statement doesn’t work out, the else statement will serve as a back-up so that the code can still print results.


    • 3. The if-else if-else Ladder

  • Used when you have multiple possibilities to test in order. Java checks conditions from top to bottom. As soon as it finds one condition that is true, it runs that block and skips everything else below it. But when the first few conditions are false, it will check all conditions until it finds one that returns true.


    • 4. The Switch Case

  • Evaluates a single expression against multiple possible constant values (called case labels). It is often cleaner and easier to read than a long if-else ladder when checking a single variable against specific fixed values.


    • Sample Code ALL Conditional Structures:

                    public class Main {
                    public static void main(String[] args) {
                        boolean isRaining = true;
                        int rainIntensity = 7; 
                        String weatherForecast = "rainy";

        // 1. Simple if 
                        if (isRaining) {
                            System.out.println("Grab an umbrella!");
                        }

        // 2. if-else 
                        if (isRaining) {
                            System.out.println("Wear waterproof boots.");
                        } else {
                            System.out.println("Wear sneakers.");
                        }

        // 3. switch
                        switch (weatherForecast) {
                            case "rainy":
                                System.out.println("Plan an indoor movie night.");
                                break;
                            case "sunny":
                                System.out.println("Head to the beach.");
                                break;
                            default:
                                System.out.println("Check the forecast again later.");
                        }

        // 3. if-else if-else ladder
                        if (rainIntensity >= 8) {
                            System.out.println("Alert: Heavy downpour, stay indoors!");
                        } else if (rainIntensity >= 4) {
                            System.out.println("Notice: Moderate rain, drive carefully.");
                        } else {
                            System.out.println("Notice: Light drizzle outside.");
                        }

        /*This code demonstrates all 3 conditional structures using weather checks: 
        a simple if prompts for a jacket, an if-else picks footwear,
         and a switch casechecks if you have an umbrella specifically when it is raining.*/

        OUTPUT: 
            Grab an umbrella!
            Wear waterproof boots.
            Plan an indoor movie night.
            Notice: Moderate rain, drive carefully.
                    }
                }
