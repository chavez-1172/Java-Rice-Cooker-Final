Java Programming Language

Arrays

Think of an array as your ultimate organizational chest when you have a big collection of items to manage or store all at once.


What is an Array?

  • An Array is a fixed-size container that holds multiple values of the same data type (Example, all Strings, all ints, or all booleans).

    • Key Rules of Arrays

    1. Once you create an array with a specific size (ex, 5 slots), you cannot change its size later.
    2. Java starts counting slots at 0, not 1!
    Slot 1 is index 0
    Slot 2 is index 1
    Slot 3 is index 2

    Declaring and Accessing Arrays

  • You can create an array by giving it a type, square brackets that contains the "index" which indicates how many values will be stored [ ], and a list of values inside curly braces { }. For instance, I want to have different kinds of sushi in a plate. The array is the plate, while the sushi are the values. Note that they are all sushi (same data type).


    • Sample Code Sushi Array:

                    public class sushiArray {
                    public static void main(String[] args) {
        // Create an array to hold 3 types of sushi.
                        String[] plate = {"nigiri", "maki", "urumaki"};

        // Directly print each sushi by calling its index slot or what position it's in.
                        System.out.println("First sushi: " + plate[0]);
                        System.out.println("Second sushi: " + plate[1]);
                        System.out.println("Third sushi: " + plate[2]);
                    }
                }

        Very easy to understand, right!? The array is basically like a chest in which
        you can store plenty of items (values) in. But you have to be organized (same data type).

        If you don't get what the word index or index slot is, check your dictionary!*/

        OUTPUT:

        First sushi: nigiri
        Second sushi: maki
        Third sushi: urumaki
