Java Programming Language

Private

Accessible only inside the exact class where it is declared. It is best used for protecting object variables from unauthorized external changes. Think of is as an inside joke that only those in the same circle of friend understands.



Public

  • Accessible from any class anywhere in the project. Best used for methods you want external code to call freely. Think of it as a public library that everyone has access to, and everyone can go to.


    • Default

  • Accessible only by classes within the same folder (package). No keyword is written before the variable or method. Think of it as a rule that only those in the same classroom or section knows.


    • Protected

  • Accessible within the same package and by any child classes (subclasses) that inherit from it, even in different packages. From the word inherit those who inherit it are the only one who has access to it. Think of it as a child inheriting a company from his/her parents. Only that child has access to it.
