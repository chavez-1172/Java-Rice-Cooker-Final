Java Programming Language

Inheritance

Inheritance allows a child class to automatically reuse fields and methods from a parent class using the extends keyword.


Think of a Character! A Wizard inherits basic character traits (like walking) from a regular player, but adds its own special attribute or special skill.


Sample Code Wizard Inheritance:

                public class Player {
        //The Parent class with a method walk().

                    void walk() {
                        System.out.println("Walking");
                    }
                }

                public class Wizard extends Player {
        //The child class also with an inherited method walk() and additional method castSpell().

                    void walk(){
                        System.out.println("I can also walk.")
                    }
                    void castSpell() {
                        System.out.println("Heal");
                    }
                }

        /*In summary, inheritance is the process of 
        passing down the attributes and methods of the parent class
        to the child class.
        
        Note that the attributes and methods of the parent class will NOT
        be passed down unless you used the keyword extends
        when creating the child class. Look at the example code above.

        You can experiment more with this by trying to code by yourself!*/
