Java Objects and Methods

Now that you have a class blueprint, let me show you how to build actual Objects from it!


What is a Method?

A method in Java is a block of code inside a class that performs a specific action. Think of a method as a command or action button you can press whenever you want your object to do something!



The 3 Key Parts of a Method

When you define a method, you tell Java three things:


Return Type: What kind of data the method gives back after running (void if it gives back nothing, int for numbers, String for text).
Method Name: The name you use to call the action (written in camelCase).
Parameters (Optional): Inputs passed inside parentheses () that the method needs to do its job.

Sample Code Creating a Method:

                public class Mimming{
                    public static void main(String[] args){
       
                        void eatFish(String treat){
                            System.out.println("Mimming ate a fish.");
                    }
                }
        //In this code sample, we created a method named eatFish.

        The void is the return type, meaning the method wont return anything.

        The (String treat) is the parameter, which we can put a value into once
        the method has been called.

        The System.out.println is the ACTION the method will do. It will print
        the text.
            

        OUTPUT: 
        Mimming ate a fish.

Why Use Methods?

Instead of writing the same code over and over, you write it once in a method and call it whenever you need it.


Methods break complex programs into small, clean, and organized steps.
