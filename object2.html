Now that you have a class blueprint, let me show you how to build actual Objects from it!


What is an Object?

An Object is a concrete, real instance built directly from a class blueprint. While a class is the blueprint, an object is the actual physical item stored in your computer's memory (instantiation). Think of it as real-world objects. In our previous Chevrolet class example before, you can think of it as one of a car's object such as a spare tire.



Each object created from the same class has its own independent copy of the fields defined in that class.


Instantiating and Using Objects

  • You create objects using the new keyword, then use dot notation (.) to access their fields and methods.

    • Calling Methods on an Object

    Instantiate it using the new keyword.
    Use dot notation (.) to access its fields and run its methods.

    As an example code, let's have the frog named Pep to demonstrate to us how to call a method through an object!



    Sample Code Pep Object and Method:

                    public class Frog{
        Create a class with attributes.

                    String frogName;

        Create a method or behavior.
                    void eatFly(){
                        System.out.println(frogName + " ate a fly!");
                    }
            
         Creating an object and calling the method on the Main method.
                    public static void main(String[] args){
       
        Create a new Frog object named pep.
                        Frog pep = new Frog();
                        pep.frogName = "Pep";

        Call the method eatFly().
                        pep.eatFly();
                    }
                }

        //In this code sample, we created a class named Frog.

        The frogName is the variable where we will put the name of the 
        frog object.

        We also created a method named eatFly which prints a statement once it is called.

        On the Main method,  we created a new Frog object named pep, and
        assigned a value to the frogName variable which is Pep, the frog's name. 

        Now you have an object!

        Then how did we call the method?  we called it by using the
        objects name (pep) and used the dot ( . ) notation, 
        followed by open and close parentheses.

        Note that the method won't execute by itself. You have to
        call it on the main method as shown in the sample code.
            

        OUTPUT: 
        Pep ate a fly!
