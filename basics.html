Java Cheat Sheet

Rules To Remember in Java

Here is your beginner-friendly cheatsheet with simple, direct rules to keep in mind:


1. Don't Forget the Semicolon ;

  • Think of this as pressing "Enter" on a command. Every single line of code needs a semicolon at the end, or Java gets confused about where to stop.

    • 2. Watch Your Capital Letters!

  • Java is super sensitive about uppercase and lowercase. To Java, "main" and "Main" are completely different words. If something isn't working, double-check your spelling and caps.

    • 3. Match Your File Name to Your Class Name

  • When you name your main group of code (called a Class), your file name on your computer must be spelled and capitalized the exact same way.

    • 4. Keep Your Curly Braces {} in Pairs

  • Curly braces group your code together into sections. Every time you open one {, make sure you close it } when you're done!

    • 5. Single Quotes vs. Double Quotes

  • Use single quotes 'a' when you only have one single letter or character.
    Use double quotes "Hello!" when you have words or full sentences.

    • 6. Tell Java What Kind of Data You Are Using

  • Before you save any information, you have to tell Java what type it is like a whole number, a decimal number, a true/false boolean, or text!

    • 7. Counting Always Starts at Zero!

  • In Java lists or collections, the very first item isn't #1 but it's #0! The second item is #1, and so on.

    • 8. println vs. print

  • When you want to show text on the screen:
    println prints your message and creates a brand-new line.
    print prints your message and leaves the cursor right next to it.

    • 9. Use Comments for Your Own Notes

  • You can write notes to yourself anywhere using // for a single line. Java will totally ignore them when running your code, so feel free to write reminders!

    • 10. The static main Method

  • Whenever you run a Java program, Java looks for this exact header line.
    The main method is always placed directly inside a class in Java.
    public static void main(String[] args)

    • 11. Where to Use (), [], and {}


  • Parentheses () — For Actions and Conditions

  • Placed right after a function or object name to hold inputs and holds conditions inside if statements or loops.

  • Brackets [] — For Lists and Positions

  • Used when declaring an array, which is a list of items of the same type and to grab a specific item out of a list by its index number.

  • Curly Braces {} — For Code Blocks and Boundaries

  • Encloses the body of classes, methods, if statements, and loops to mark where they begin and end.

    • 12. Variable Naming Styles


  • camelCase

  • The first word starts with a lowercase letter. Every following word starts with an uppercase letter, with no spaces in between!

  • PascalCase (Also called UpperCamelCase)

  • Every word starts with an uppercase letter, including the very first word. Mostly used in classes names and not variable names.

  • lowercase_with_underscores

  • Every letter is lowercase, and words are joined by an underscore (_).

    • 13. What Symbols Can a Variable NOT Start With?


  • Numbers

  • Any digit from 0 to 9.

  • Mathematical Symbols

  • +, -, *, /, =, %, <, >, ^

  • Punctuation & Special Characters

  • @, #, !, ?, &, ., ,, :, ;, ~, | (except the dollar $ sign).
  • Brackets & Parentheses

  • (, ), [, ], {, }
