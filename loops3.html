The Three Main Types of Loops

A loop is a smart control structure that repeats a block of code over and over until a specific condition tells it to stop. It saves you time, keeps your code clean, and does all the repetitive work automatically!


2. The While Loop

  • The WHILE loop is used when you want to repeat something as long as a condition stays true, but you don't know in advance how many times it will take. For instance, I want a shark named Sharknado to eat until it is full!

    • Sample Code Shark While Loop:

                    public class whileLoopSharknado {
                    public static void main(String[] args) {
                        boolean isHungry = true;
                        int fishEaten = 0;

                        while (isHungry) {
                            grassEaten++;
                            System.out.println("Sharknado munches  " + fishEaten + " fish/es.");

        // Shark gets full after 3 bundles
                            if (fishEaten == 3) {
                                isHungry = false;
                                System.out.println("Shark is full! Time for a nap.");
                            }
                        }
                    }
                }

         /*In this sample code, we created a while loop and declared 
        two variables.

        The boolean isHungry with a true value, which represents that
        Sharknado is hungry.
        
    
        The int fishEaten with a 0 value, which represents the
        number of fish sharknado has eaten. Well for now, there is 0.
        
        After that, we gave the while loop a condition that when fishEaten
        becomes equivalent to three after the loop has executed and increments it by one,
        it will print the statement below.

        However, in the if-condition, we gave a condition that when fishEaten 
        becomes equivalent to three, isHungry will turn into false.
        This will make the loop stop entirely and prints the second statement below.
        
        Here is the output of the code for better understanding.*/    

        OUTPUT:

        Sharknado munches 1 fish/es.
        Sharknado munches 2 fish/es.
        Sharknado munches 3 fish/es.
        //The loop stops since it reaches 3.
