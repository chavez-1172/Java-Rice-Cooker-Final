Abstraction

Abstraction is hiding complex background steps and showing only essential operations to the user.


Think of a coffee machine. You just press a button to brew coffee without needing to worry about how it process inside the machine.


Sample Code Coffee Machine Abstraction:

                abstract class CoffeeMachine {
                    abstract void brew(); 
                }
        //You have to use the keyword abstract when creating classes and variables.

                class Brewer extends CoffeeMachine {
                    void brew() {
                        System.out.println("Brewing coffee");
                    }
        //Added an action to the abstract method.

                }

        /*In summary, abstraction is the act of 
        creating classes and variables like a simple layout. 
        Looking back at the sample code, the method on the abstract class didn't 
        contain anything. 

        It only had an action when it was declared on the Main method.

        Try it yourself!
            

        OUTPUT: 
        Brewing coffee
