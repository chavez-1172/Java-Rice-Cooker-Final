What is a Class?

A Class is an abstract blueprint or template used to define the structure of something you want to represent in your program. By itself, a class is just an idea on paper it does not take up physical object space in memory until you build something from it. As an example, think of a blueprint for a house It's just a blueprint, and not the actual house yet.


A class defines two primary components:

  • Fields (Attributes): Variables that describe what state or data it holds.

  • Methods (Behaviors): Functions that define what actions it can perform.
