Data Types & Variables

Think of a variable as a labeled storage box in memory used to store data. In Java, you must declare what kind of data fits inside the box (its data type).


For instance, dog is an animal, banana is a fruit, and blobfish is a fish.



The same logic applies to variables and data types. Each data type can only accept a value that fits into their category.


1.Primitive Types (Direct Values)

These types of variables hold single, basic pieces of data.


int (Integers):

Holds whole numbers only as values.

Example: int watermelonSlices = 8;


double (Decimals):

Holds numbers that contain decimals as values.

Example: double catWeight = 4.57788778;


char (Single Character):

One letter or symbol enclosed in 'single quotes'.

Example: char rank = '?';


boolean (True/False):

A simple on/off or true/false switch. This value only outputs true or false.

Example: boolean amlHungry = true;

2. Reference Types (Complex Data)

These hold complex data or points to bigger items in memory. From the term "Reference", think of it as an object that points to another storage where data is stored.


String:

Text written in "double quotes" and accepts text values, from words to sentences.

Example: String mimmingName = "Momo";


Arrays:

A grouped list of items of the same type. In this example, all values placed inside the treats[] array are all String variables.

Example: String treats[] = {"Fish", "Chicken", "Milk"};
