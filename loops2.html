The Three Main Types of Loops

A loop is a smart control structure that repeats a block of code over and over until a specific condition tells it to stop. It saves you time, keeps your code clean, and does all the repetitive work automatically!


1. The for Loop

  • The FOR loop is used when you know the exact number of times you want to repeat something before you even start. For instance, I want the capybara to eat fro a total of 5 times only.


    • Sample Code Capybara For Loop:

                    public class forLoopCapybara {
                    public static void main(String[] args) {
        // Repeat exactly 5 times
                        for (int i = 1; i <= 5; i++) {
                            System.out.println("Capybara takes a bath in a hot spring 
                            for " + i + " time /s.");
                        }
                    }
                }

         /*In this sample code, we created a for loop and declared 
        the int variable i, with a value of 1. 
        
        After that, we gave it a condition that as 
        long as i is less than or equal to five, it will increment (i++)
        or increase by one continuously. 
        
        And then on the string concatenation, the statement will be printed and the ( i ) 
        will be changed to the total value until it reaches 5.*/

        OUTPUT:

        Capybara takes a bath in a hot spring for 1 time /s.
        Capybara takes a bath in a hot spring for 2 time /s.
        Capybara takes a bath in a hot spring for 3 time /s.
        Capybara takes a bath in a hot spring for 4 time /s.
        Capybara takes a bath in a hot spring for 5 time /s.
