Java Programming Language

Relational Operators (Comparing Things)

These compare two values to see how they relate to each other:


1. Equal To ==

  • Uses two equal ( == ) symbols and checks if two values are identical. Returns true if they match, and false if they do not.

  • (Example, 5 == 5 is true).

    • Sample Code (the yellow texts are comments):

                    public class equalTo{
                    public static void main(String[] args){
                        int age = 18;

        //Equal to (==)

                        if (age == 18) {
                            System.out.println("You just became an adult!");
                        }

         /*Since the int variable named age has a value of 18, the if condition will return true. 
        Because of this, the output will print the statement.*/

         /*If you're wondering what the if{} condition was used for, 
        keep reading because we will explain that later on!*/
                    }
                }

    2. Not Equal To ! =

  • Uses the exclamation point ( ! ) and equal ( = ) symbol and checks if two values are different. Returns true if they are not the same.

  • (Example, 5 != 3 is true).

    • Sample Code (the yellow texts are comments):

                    public class notEqualTo{
                    public static void main(String[] args){
                        int age = 18;

        //Not Equal to (! =)

                        if (age != 0) {
                            System.out.println("Age is valid.");
                        }

         /*Take note that the value of age was 18, but it still read as true in the conditions.

        This is because Java read the code as:
        "if the age is not equal to 0, then it is true." 
        That is the purpose of the ! = operator.*/
                    }
                }

    3. Greater than >

  • Uses the greater than ( > ) symbol and checks if the value on the left is larger than the value on the right.

  • (Example, 7 > 4 is true).

    • Sample Code (the yellow texts are comments):

                    public class greaterThan{
                    public static void main(String[] args){
                        int age = 18;

        // Greater than (>)

                        if (age > 12) {
                            System.out.println("You are older than a child.");
                        }   

         /*Is 18 a larger number than 12? Yes. 

        That's why when compared using the > symbol, it returns true and prints the output.
        If the value of age was smaller however, 8 for instance, 
        it will return false and will not print any output.*/
                    }
                }

    4. Less than <

  • Uses the less than ( < ) symbol and checks if the value on the left is larger than the value on the right.

  • (Example, 2 < 8 is true).

    • Sample Code (the yellow texts are comments):

                    public class lessThan{
                    public static void main(String[] args){
                        int age = 18;

         // Less than (<)

                        if (age < 21) {
                            System.out.println("You are under 21.");
                        }

         /*Is 18 a smaller number than 21? Absolutely!

        That's why when compared using the < symbol, it still returns true and prints the output.
        If the value of age was larger however, 67 for instance, 
        it will return false and will not print any output.*/
                    }
                }

    5. Greater than or equal to >=

  • Uses the greater than ( > ) and equal ( = ) symbol and checks if the value on the left is either larger than or equal to the value on the right.

  • (Example, 5 >= 5 is true).

    • Sample Code (the yellow texts are comments):

                    public class greaterThanOrEqualTo{
                    public static void main(String[] args){
                        int age = 18;

         // Greater than or equal to (>=)

                        if (age >= 18) {
                            System.out.println("You are eligible to vote.");
                        }

         /*This operator will check 2 conditions.

        Is 18 greater than 18? No, so that is false. 
        But is 18 equal or equivalent to 18? Yes! That's why it is still true.*/
                    }
                }

    6. Less than or equal to <=

  • Uses the less than ( < ) and equal ( = ) symbol and checks if the value on the left is either smaller than or equal to the value on the right.

  • (Example, 3 <= 5 is true).

    • Sample Code (the yellow texts are comments):

                    public class lessThanOrEqualTo{
                    public static void main(String[] args){
                        int age = 18;

         // Less than or equal to (<=))

                        if (age <= 12) {
                            System.out.println("You get a child discount.");
                        } else {
                            System.out.println("Standard ticket rate applies.");
                        }

         /*This operator will check 2 conditions as well.

        Is 18 less than 12? No, so that is false. But is 18 equal or equivalent to 12? 
        STILL A NO! That's why it is false.

        It shouldn't print any output. But looking closer, you will see an else statement.
        Now what is an else statement for? 
        It is used as a back-up code that will execute when the if condition returns false.
                        
        We will talk about it more later on!*/
                    }
                }
