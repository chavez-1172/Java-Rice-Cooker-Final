Polymorphism

Polymorphism allows different classes to have their own unique versions of the exact same method name.


Duck quacks and a cat meows, but both are responding to the exact same make a noise command.


Sample Code Duck Polymorphism:

                class Animal {
                    void makeNoise() {
                        System.out.println("Any animal sound");
                    }
                }

                class Duck extends Animal {
                    @Override
                    void makeNoise() {
                        System.out.println("Quack quack"); 
                //the duck class used the same method
                but it prints a different statement through method overloading (see your dictionary).
                
                    }
                }

        /*In summary, polymorphism is the act of 
        using the same attributes or methods and
        being able to change it in different forms through overloading and overriding.

        Don't forget to check the dictionary for unfamiliar words and terms!*/
