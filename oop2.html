Encapsulation

Encapsulation is hiding class variables behind private so they cannot be changed directly from outside the class.


Think of a Capsule Pill! The chemical ingredients are sealed inside a shell so no one can mess or change the contents inside directly.


Sample Code Pill Encapsulation:

                public class Pill{
                    private String chemical = "Aspirin";
        //The chemical is locked inside a pill (the data is encapsulated in a private variable).

                    public void takePill() {
                        System.out.println("Taking " + chemical + ".");
                    }
        //Uses a public method to use the encapsulated variable.
                }

        /*In summary, encapsulation is the process of enclosing your data in a private variable or class
        so that it is not easily changed or modified.

        You can experiment more with this by trying to code by yourself!*/
            

        OUTPUT (This will not print unless method is called in the Main method.): 
        Taking Aspirin.
